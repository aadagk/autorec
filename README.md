# Автозапись звонков (Samsung / One UI)

Работает как AutoRec: служба спец. возможностей сама нажимает «Еще» → «Записать» в экране звонка Samsung.

## Сборка APK без Android Studio
1. Создайте репозиторий на github.com, загрузите в него всё содержимое этой папки (включая скрытую `.github`).
2. Вкладка **Actions** → **Build APK** → дождитесь зелёной галочки.
3. Внутри запуска скачайте артефакт **AutoRecord-apk** (zip с `app-debug.apk`).

Либо откройте папку в Android Studio → Build → Build APK.

## Установка и настройка (на телефоне)
1. Установите APK, откройте «Автозапись».
2. Кнопка 1 — дайте доступ «Телефон».
3. Кнопка 3 — откройте спец. возможности → Установленные приложения → Автозапись → попробуйте включить.
   Если система пишет «Ограниченные настройки» — вернитесь, нажмите кнопку 2 → ⋮ (справа вверху) →
   «Разрешить ограниченные настройки», затем снова включите службу.
4. Кнопка 4 — снимите ограничения батареи. Также: Настройки → Батарея → Фоновые ограничения → добавьте
   «Автозапись» в «Никогда не спящие».
5. Сделайте тестовый звонок. В журнале приложения должно появиться «Открываю меню «Еще»» и «Нажал «Записать»».

## Если не заработало
Включите «Подробный лог…», сделайте звонок, затем в приложении нажмите «Поделиться журналом» и
«Поделиться дампом экрана звонка» — по дампу видно точные названия кнопок и пакет звонилки,
и правятся они в `RecService.java` (массивы REC, MORE, PKG_PARTS).
